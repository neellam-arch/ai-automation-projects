Hands-on projects building practical AI automation skills with Python and n8n.
Each project is based on a real workflow from education admissions, where I
handle student enquiries and course enrolment.

## Projects

### 1. Student Enquiry Sorter
**Problem:** Student enquiries arrive mixed together, and some are missing
contact details, which slows down follow-up.

**What it does:**
- Sorts enquiries by course (PTE UKVI, Python, AI Tools)
- Flags enquiries with missing email addresses for follow-up
- Saves a separate JSON file for each course

**Skills:** Python, JSON, data filtering, data-quality checks, file output

**Run it:** Open `project1_enquiry_sorter.ipynb` in Google Colab and run all cells.
